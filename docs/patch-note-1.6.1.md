# v1.6.1 — La cinématique complète (en test dans le labo)

## Ce qu'il faut regarder
Lien : `https://hm3282039-art.github.io/qzeshjkgf/?lab`

Deux boutons en haut :
- **Cinématique complète** — la scène entière, 5 actes, ~4,6 s.
- **Révélation seule** — l'ancien carton du nom, 4 styles, ~1,5 s.

## Les 5 actes (le bandeau sous l'image avance en même temps)
| Acte | Moment | Ce qui se passe |
|---|---|---|
| Entrée | 0 % | les barres noires claquent, le monde s'éteint, la caméra pousse |
| Nom | 18 % | le nom de l'ultime tombe lettre par lettre |
| Action | 33 % | le héros joue son geste |
| Impact | 52 % | flash, négatif, chiffres de dégâts, fissures / pluie / colonnes |
| Sortie | 70 % | la poussière retombe, fondu au noir |

## Six gestes différents (choisis d'après le texte de l'ultime)
- **Coup au sol** (Kael, Thorne, Gorm) : bond, retombée, sol fendu, ondes.
- **Traversée** (Lyra, Vespera, Bran, Sable, Zephyr) : images fantômes, entaille diagonale.
- **Pluie du ciel** (Seren, Pyrrha, Nell, Ilse, Aurore, Ashka, Morwen) : le ciel s'ouvre, traits qui tombent un par un.
- **Bénédiction** (Aldric, Elara, Orlan, Rook, Oskar, Vesper) : le héros s'élève, colonnes de lumière.
- **Effondrement** (Nyx) : tout est aspiré vers un point noir, puis relâché.
- **Rayon** (Corvin, Noktis, Sylvaine, Mira) : armé, puis trait qui traverse l'écran.
